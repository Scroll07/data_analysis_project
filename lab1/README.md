# Анализ данных: Медицинское страхование

## Описание набора данных
В проекте используются данные о медицинском страховании (`insurance.csv`). Набор включает следующие показатели:
* **age** (возраст) — числовой тип (int64)
* **sex** (пол) — категориальный тип (category)
* **bmi** (индекс массы тела) — числовой тип (float64)
* **children** (количество детей/иждивенцев) — числовой тип (int64)
* **smoker** (статус курения) — категориальный тип (category)
* **region** (регион проживания) — категориальный тип (category)
* **charges** (расходы на страховку) — числовой тип (float64)

## Подключаемые библиотеки
Для выполнения проекта использовались следующие библиотеки Python:
* **pandas** — для считывания данных, работы с датафреймами и анализа.
* **matplotlib.pyplot** — для базовой визуализации графиков.
* **seaborn** — для построения расширенных статистических графиков (гистограммы, диаграммы размаха, диаграммы рассеяния).

## Методы предобработки данных
В ходе выполнения работы были применены следующие методы предобработки:
1. **Проверка на наличие пропусков**: осуществлена с помощью связки методов `df.isnull().sum()`. Пропусков в данных не обнаружено.
2. **Преобразование типов данных**: для оптимизации работы с памятью и корректной визуализации текстовые колонки (`sex`, `smoker`, `region`) были преобразованы в категориальный тип с помощью метода `astype('category')`.
